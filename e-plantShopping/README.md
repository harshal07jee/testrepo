# Paradise Nursery Shopping Application

Paradise Nursery is an online shopping application for browsing and purchasing a variety of houseplants.

## Features
- **Landing Page:** Engaging welcome screen featuring Paradise Nursery with background visuals and a "Get Started" call-to-action button.
- **Product Catalog:** Houseplants grouped into 3 distinct categories (Air Purifying, Aromatic Fragrant, and Low Maintenance), featuring 6 unique plants per category with names, descriptions, images, and prices.
- **Interactive Shopping Cart:** Powered by Redux Toolkit for real-time global state management.
  - Dynamically updates cart badge count.
  - "Add to Cart" button automatically disables once added.
  - Increase, decrease, or remove item quantities.
  - Automatic subtotal and total cost computation.
  - Checkout button with "Coming Soon" prompt and Continue Shopping navigation.

## Technologies Used
- React + Vite
- Redux Toolkit
- JavaScript (ES6+)
- CSS3
